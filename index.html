Integração com API pública

Esta aplicação foi desenvolvida com HTML, CSS puro e JavaScript. O método fetch() consulta a PokéAPI, e o DOM é manipulado para criar cada card dinamicamente, sem cadastrar personagens manualmente no HTML.
