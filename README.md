# PokéCards - Consumo da PokéAPI

Projeto acadêmico desenvolvido por **Liliana Terrazas Balderrama** para a disciplina de desenvolvimento front-end do curso de Engenharia de Computação EAD.

## Objetivo

Criar um site estático utilizando HTML, CSS puro e JavaScript, consumindo dados de uma API pública e exibindo personagens em cards gerados dinamicamente.

## Tecnologias

- HTML5
- CSS3 puro
- JavaScript
- Fetch API
- DOM
- Local Storage
- PokéAPI

## Funcionalidades

- Consulta de personagens pela PokéAPI com `fetch()`.
- Cards criados dinamicamente pelo JavaScript.
- Nome, imagem, número, tipo, altura e peso.
- Pesquisa por nome ou número do Pokémon.
- Botão para carregar mais personagens.
- Favoritos armazenados no `localStorage`.
- Tratamento de erros.
- Layout responsivo para desktop e celular.

## Estrutura

```text
pokemon-api-liliana/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como executar

Abra o arquivo `index.html` em um navegador. Para desenvolvimento, também é possível utilizar a extensão Live Server do VS Code.

## API

Os dados são consultados da PokéAPI REST v2 por JavaScript durante a execução da página.
